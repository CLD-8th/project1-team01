# 역할 분담표 (펩시미만잡)

> 비고 등 API 상세는 [URL/API 목록](03_API목록.md) 참고.

## API 기능

| # | 기능 | Method | URL | 담당자 |
|---|---|---|---|---|
| 1 | 도서 목록 | GET | `/api/books` | 홍정민 |
| 2 | 도서 상세 | GET | `/api/books/{bookId}` | 홍정민 |
| 3 | 도서 등록 | POST | `/api/books` | 홍정민 |
| 4 | 거래 요청 | POST | `/api/books/{bookId}/requests` | 문병현 |
| 5 | 마이페이지(등록한 책) | GET | `/api/mypage/books` | 김시웅 |
| 6 | 마이페이지(받은 요청) | GET | `/api/mypage/requests/received` | 김시웅 |
| 7 | 마이페이지(보낸 요청) | GET | `/api/mypage/requests/sent` | 김시웅 |
| 8 | 요청 수락 | POST | `/api/requests/{requestId}/accept` | 문병현 |
| 9 | 요청 거절 | POST | `/api/requests/{requestId}/reject` | 문병현 |
| 10 | 사진 업로드 | POST | `/api/books/images` | 홍정민 |
| 11 | 인기 도서 랭킹 TOP 10 | GET | `/api/books/ranking` | 전동환 |
