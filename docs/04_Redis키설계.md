# Redis 키 설계 (펩시미만잡)

| 키 이름 | 자료구조 | TTL | 무효화 시점 | 용도 |
|---|---|---|---|---|
| `book:ranking` | Sorted Set | 없음(누적) | 거래 요청(가격 제시·교환 제시) 발생 시 점수 +1 | 인기 도서 랭킹 TOP 10 |

> 조회수는 새로고침으로 부풀려질 수 있어 랭킹 기준에서 제외하고, 거래 요청 수만 반영. 추후 확장 시 조회수·기타 요소를 가중치로 섞어 점수를 합산하는 방식으로 발전 가능(예: `ZADD`에 넣기 전에 `score = w1*요청수 + w2*조회수 + ...` 계산).
