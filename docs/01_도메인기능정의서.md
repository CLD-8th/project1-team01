# 도메인·기능 정의서 (펩시미만잡)

> 기획서가 아니라 AWS 설계의 입력값. 각 항목은 반드시 하나 이상의 설계 결정으로 이어져야 함.

## 도메인 개요

- 한 줄 정의: 본인이 읽었던 책을 등록하고 다른 사람의 책과교환 교환하거나 판매하는 서비스
- 대상 사용자: 자신의 책을 교환하거나 판매하고싶은 사용자
- 서비스 지역: 대한민국

## 핵심 기능 (2개 권장, 최대 3개)

1. 도서 등록·조회(상태: 거래중, 거래완료)
2. 교환 요청·수락(가격 제시 또는 책 교환 제시)
3. 마이페이지(내가 등록한 책 목록, 거래 상태 확인)

## Redis 활용 기능 (필수 1개)

- 기능: 인기 도서 랭킹 TOP 10(거래 요청 수 기반) + 동시 수락 방지 락
- 자료구조: Sorted Set(랭킹) / String, SET NX EX(락)
- 무효화 시점: 등록한책이 거래완료 되기전까지 랭킹 누적

## 파일 요소 (있으면 작성)

- 파일 종류: PDF, 이미지 파일
- 최대 크기: 5MB
- 조회 빈도: 상세 조회 시 노출

## 데이터 특성

- 주요 엔티티: book,user,exchange_request
- 읽기/쓰기 비율: 8 : 2

- DAU: 2000
- 피크 시간대: 21시
- 피크 동시접속: 200
- 급증 이벤트: 수능 이후, 휴가 시즌, 책관련 이슈 급증

- 허용 데이터 유실(RPO): 5분
