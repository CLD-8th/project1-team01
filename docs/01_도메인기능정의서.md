# 도메인·기능 정의서 (펩시미만잡)

> 기획서가 아니라 AWS 설계의 입력값. 각 항목은 반드시 하나 이상의 설계 결정으로 이어져야 함.

## 도메인 개요

- 한 줄 정의: 본인이 읽었던 책을 등록하고 다른 사람의 책과 교환하거나 판매하는 서비스
- 대상 사용자: 독서를 즐기는 사람
- 서비스 지역: 국내 (가정)

## 핵심 기능 (2개 권장, 최대 3개)

1. 도서 등록·조회(상태: 거래중, 거래완료) — 사용자는 안 읽는 책을 등록하고, 다른 사용자는 목록·상세에서 원하는 책을 찾음
2. 교환 요청·수락(가격·책 사진 조합으로 요청 종류 결정: 교환 요청 / 웃돈 주고 교환 제안 / 나눔 요청 / 구매 제안) — 사용자는 제안 가격과 책 사진(선택)을 넣어 요청하고, 등록자는 여러 요청 중 하나를 수락함
3. 마이페이지(내가 등록한 책 목록, 거래 상태 확인) — 사용자는 자신이 등록한 책과 보낸·받은 요청이 어떤 상태인지 확인함

## Redis 활용 기능 (필수 1개)

- 기능: 인기 도서 랭킹 TOP 10(거래 요청 수 기반) + 동시 수락 방지 락
- 자료구조: Sorted Set(랭킹) / String, `SET NX EX`(락)
- 무효화 시점: 랭킹은 무효화 없이 요청 발생 시마다 점수 누적 / 락은 수락 처리 완료 시 삭제, 또는 TTL 만료로 자연 해제

## 파일 요소 (있으면 작성)

- 파일 종류: 책 표지·상태 사진(이미지)
- 최대 크기: 5MB(가정)
- 조회 빈도: 책 상세 조회 시 노출

## 데이터 특성

> (가정 — 팀 검토 필요)

- 주요 엔티티: user, book, exchange_request
- 읽기/쓰기 비율: 8 : 2 — 책 목록·상세 조회가 대부분, 등록·요청·수락은 상대적으로 적음

## 트래픽 특성

> (가정 — 팀 검토 필요)

- DAU: 3,000
- 피크 시간대: 21시(퇴근·하교 후 여유 시간)
- 피크 동시접속: 300명
- 급증 이벤트: 방학 시작 직후(안 읽는 책 정리 수요 증가), 평시 대비 ×2

## 중요도

> (가정 — 팀 검토 필요)

- 허용 중단 시간(RTO): 30분
- 허용 데이터 유실(RPO): 5분
- 가용성 목표: 99.9%
