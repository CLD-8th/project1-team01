# 역할 기반 매핑 (펩시미만잡)

`compose.yaml`에 적힌 구성요소 → AWS 서비스로 매핑. 배포 방식이 아니라 역할 기준.

| Docker 구성요소 | 역할 | 역할 기반 매핑(AWS) |
|---|---|---|
| app 컨테이너 | 애플리케이션 티어 | EC2 Auto Scaling 또는 ECS Fargate |
| 호스트 포트 8080 | 진입·부하 분산 | ALB(+ Route 53) |
| db 컨테이너 | 데이터 티어 | RDS for MySQL 8.4 |
| cache 컨테이너 | 캐시·상태 저장 | ElastiCache(Redis OSS) |
| uploads 볼륨 | 파일 저장 | S3 |
| compose 네트워크 | 네트워크 경계 | VPC + 3계층 서브넷 + 보안 그룹 |
| `.env` | 비밀 정보 | Secrets Manager / SSM Parameter Store |
| `docker logs` | 로그·지표 | CloudWatch Logs·Metrics |

(팀 구성이 확정되면 실제 compose.yaml 기준으로 다시 확인)
