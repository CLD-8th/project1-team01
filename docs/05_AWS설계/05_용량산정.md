# 용량 산정 (펩시미만잡)

```
RPS(초당 요청 수) = 동시접속자 ÷ Think Time
필요 인스턴스 수 = 피크 RPS ÷ 인스턴스 1대 처리량  → 올림
Auto Scaling 설정 = 최소(평시) / 희망(평시) / 최대(급증 대비)
```

| 항목 | 값 | 비고 |
|---|---|---|
| 피크 동시접속 | (미정) | 정의서의 가정 수치 |
| Think Time | (미정) | |
| 피크 RPS | (미정) | |
| 급증 RPS | (미정) | |
| 인스턴스 1대 처리량 | (미정, 가정) | 실제 값은 부하 테스트(k6)로 측정 |
| Auto Scaling | 최소 __ · 희망 __ · 최대 __ | 최소 2는 AZ 이중화 조건 |
