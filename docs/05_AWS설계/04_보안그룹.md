# 보안 그룹 체인 (펩시미만잡)

소스는 IP 대역이 아니라 "앞 단계의 보안 그룹 ID"로 지정.

| 보안 그룹 | 인바운드 | 소스 | 목적 |
|---|---|---|---|
| alb-sg | 443, 80 | 0.0.0.0/0 | 사용자 접근 |
| app-sg | 8080 | alb-sg | ALB에서만 앱 접근 |
| db-sg | 3306 | app-sg | 앱에서만 DB 접근 |
| cache-sg | 6379 | app-sg | 앱에서만 캐시 접근 |

관리 접속: SSM Session Manager 사용(SSH 22 개방 안 함). 대안: Bastion Host(소스는 관리자 IP/32로 제한).
